Vom FormElement zum Steuerelement

Der FormElementRenderer bekommt eine Liste von Beschreibungen und baut daraus ein vollständiges, validiertes Formular. Kein Feld ist im Markup fest verdrahtet: Die Properties jedes FormElement entscheiden, welches HTML-Element entsteht und wie es sich verhält.

Eingabe: ein FormElement
new FormElement {
 Key      = "Email",
 Label    = "Email",
 Type     = FormElementType.Email,
 Required = true,
 Note     = "Die Annotation [EmailAddress] prüft, ob es sich um eine gültige E-Mail-Adresse handelt."
}
→
Ausgabe: im Browser

Label wird zum Label, Required zum Stern und zum required-Attribut, Note zum Info-Icon, Type zu <input type="email">.

Der Weg im Überblick

Sieben Stationen von der Liste bis zum DOM

Oben steht der Parameter FormElements. Er wird in Seiten zerlegt, dann wird Feld für Feld sortiert: Struktur oder Eingabe, Gruppe oder Einzelfeld. Erst RenderEditableFormElement entscheidet anhand von field.Type, welcher Baustein das HTML erzeugt. Der gestrichelte Pfeil ist der Rückweg der Benutzereingabe.

Der Rückweg

  
Von der Eingabe zurück ins Objekt

  
Der Renderer schreibt jede Änderung direkt in das übergebene FormElement. Die aufrufende Komponente arbeitet also immer mit derselben Liste, die sie hineingegeben hat.

  

   

    
1 · Ändern

    
onchange bzw. onclick setzt field.ValueString. Textfelder nutzen EventCallback.Factory.CreateBinder, Radio, CheckBox, Multiselect und Rating eigene Handler.

    
Danach feuert OnValuesChanged(FormElements).

   

   

    
2 · Prüfen

    
„Nächste Seite“ ruft ValidateCurrentPage(), „Absenden“ ruft ValidateFieldSet() für alle Felder. Geprüft werden Pflichtfelder, die Länge, Regex und das Format je Typ.

    
Hat ein Feld für die verletzte Prüfung eine eigene Meldung in ErrorMessages, erscheint diese statt des Labels in der Sammelmeldung.

    
Fehlerhafte Keys landen in InvalidFieldKeys und erhalten die CSS-Klasse is-invalid.

   

   

    
3 · Absenden

    
Ist alles gültig, feuern OnValuesChanged und OnSubmitted mit der kompletten FormElementList.

    
Per AsKeyValueDic oder AsLabelValueDic wird daraus ein Dictionary.
