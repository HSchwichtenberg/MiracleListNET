Von der Textzeile zum FormElement

MarkdownFormDSLParser.Parse(template) liest eine Formulardefinition in einer an Markdown angelehnten Kurzschreibweise. Jede Zeile wird zu höchstens einem FormElement. Die fertige FormElementList zeigt der FormElementRenderer als Formular an.

Eingabe: eine Zeile der Vorlage
+ Alter des ältesten Kindes {Zwischen 0 und 100}: [Number] 0-100 = 20

+ Pflichtfeld · {…} Tooltip · [Typ] Parameter · = Wert Vorgabewert

→
Ausgabe: FormElement
Key      = "Weitere_Personendaten_Alter_des_ältesten_Kindes"
           // Section + "_" + Label
Label    = "Alter des ältesten Kindes"
Type     = Number
Min, Max = 0, 100
Value    = "20"
Required = true
Note     = "Zwischen 0 und 100"
Group    = "Ihre Kinder"  // aus "= Ihre Kinder"
Der Weg im Überblick

Zeile für Zeile, mit Gedächtnis

Der Parser arbeitet die Vorlage zeilenweise ab. Er merkt sich das aktuelle Kapitel bzw. die aktuelle Überschrift (für den Key) und die aktuelle Gruppe. Das erste Zeichen nach dem Trimmen entscheidet über die Art der Zeile. Eine Feldzeile durchläuft danach zwei Stufen: Zuerst werden die Zusatzangaben herausgelöst, dann bestimmt die Felddefinition den Typ.

Weg einer FeldzeileStrukturzeile, ändert Zustand oder erzeugt StrukturSchleife über die Zeilen
Zum Ausprobieren

Vorlage bearbeiten, Ergebnis sofort sehen

Links steht die Klasse Fragebogen aus BO/Fragebogen.cs in der Kurzschreibweise, mit denselben Feldern und Werten wie in den Schaubildern zum AnnotatedObjectParser und zum FormElementRenderer. Zwei Felder ergeben hier bewusst einen anderen Typ, weil es dafür keine passende Annotation gibt: Bewertung1 wird zu Rating, die Altersangaben werden zu Number. Rechts läuft eine JavaScript-Nachbildung von Parse() mit denselben Regeln. Ein Klick auf eine Zeile markiert ihren Weg im Schaubild und zeigt das vollständige FormElement.

Gruppen

  
Einrückung entscheidet über die Gruppe

  

   
Eingerückt unter =
Felder mit Leerzeichen vor - oder + übernehmen die aktuelle Gruppe. Sie stehen im Renderer in einer Zeile.


= Ihre Kinder
 - Kinder: [Range] 0-10
 + Alter des ältesten Kindes: [Number] 0-100

   
Nicht eingerückt
Ein - oder + ganz links beendet die Gruppe. Jedes solche Feld bekommt eine eigene Auto-Gruppe und steht damit allein in voller Breite.


+ Lebensmotto = Weniger ist mehr.
- Telefonnummer: [Phone]

   
Zurückgesetzt
Jede Zeile mit # oder ## setzt die Gruppe ebenfalls auf null. Eine Gruppe reicht also nie über eine Überschrift hinaus.


# Weitere Personendaten
 - Geburtsdatum: [Date]
